# ⚡ OptiSys — диагностика, очистка и оптимизация Windows

Нативное десктопное приложение для комплексной инвентаризации оборудования, безопасной очистки кэша/временных файлов, ускорения системы и обновления драйверов в Windows 10/11.

---

## ✨ Основные возможности

### 1. Диагностика оборудования и системы (WMI / Storage API / Реестр)
* **Обзор и Live-дашборд:** версия и сборка ОС, модель устройства, BIOS, живой мониторинг оперативной памяти (`GlobalMemoryStatusEx`), уровень заряда и расчёт износа батареи ноутбука (паспортная vs текущая ёмкость в Вт·ч).
* **Процессор и Память:** модель CPU, ядра/потоки, базовая частота, кэши L2/L3, сокет; послотовая раскладка планок ОЗУ (`BankLabel` + `DeviceLocator`, частота, производитель, партномер).
* **Диски и S.M.A.R.T.:** физические накопители (определение `NVMe SSD` / `SATA SSD` / `HDD`, статус здоровья S.M.A.R.T., температура и наработка) и логические разделы с процентом заполнения.
* **Видео, Мониторы, Сеть, Звук, Драйверы:** точный объём VRAM из реестра (`qwMemorySize`) без ограничения 4 ГБ у WMI, прямые ссылки на официальные сайты производителей GPU (NVIDIA / AMD / Intel), фильтрация физических сетевых адаптеров, список всех PnP-драйверов с быстрым поиском и проверкой WHQL-подписи.
* **Экспорт отчётов:** сохранение полной сводки в автономный **HTML** или **JSON** в 1 клик.

### 2. Безопасная очистка и поиск крупных файлов
* **Очистка кэша и мусора:** системные и пользовательские папки `Temp` (с защитой активных сессий и файлов моложе 24 часов), кэш Windows Update (`SoftwareDistribution\Download`), отчёты об ошибках WER, Корзина, кэш шейдеров DirectX/NVIDIA/AMD, кэши браузеров (с проверкой запущенных процессов) и пакетных менеджеров (`pip`, `npm`).
* **Поиск «Пожирателей места» (> 100 МБ):** сканирование пользовательских папок с автоматической классификацией безопасности удаления:
  * `🟢 Безопасно удалить` — кэши шейдеров GPU (`*.nvph`), временные установщики в `Temp`, кэши браузеров и скачанные инсталляторы в «Загрузках»;
  * `🟡 На ваше усмотрение` — личные медиафайлы, архивы и моды игр (`*.pak`);
  * `🔴 Не трогать` — виртуальные диски WSL/Docker (`*.vhdx`) и рабочие файлы установленных программ (защищены от случайного удаления).

### 3. Оптимизация и твики Windows 11
* **Ускорение в 1 клик:** сброс DNS-кэша, очистка таблицы маршрутизации ARP, освобождение оперативной памяти (`EmptyWorkingSet` для фоновых процессов), аппаратный TRIM системного SSD (`fsutil` + `defrag /L`) и очистка устаревших пакетов хранилища `WinSxS` (`DISM /StartComponentCleanup`).
* **Быстрые переключатели Windows 11:** схема питания «Высокая производительность», отключение веб-поиска Bing в меню «Пуск», отключение рекламных рекомендаций Windows, показ расширений файлов в Проводнике.
* **Безопасная очистка реестра:** поиск осиротевших ссылок на удалённые программы с автоматическим созданием `.reg`-бэкапа перед исправлением.
* **Менеджер автозагрузки:** управление программами автозапуска через штатный механизм `StartupApproved` (полная совместимость с Диспетчером задач Windows) и оценка влияния на старт системы.

### 4. Центр обновления драйверов (Windows Update Agent API)
* Асинхронный поиск актуальных драйверов через COM API `Microsoft.Update.Session` (`BeginSearch` / `EndSearch`) с живым секундомером и мгновенной отменой.
* Выборочное скачивание и установка драйверов с отображением прогресса.

## 🛠 Требования

* **ОС:** Windows 10 / Windows 11 (x64)
* **Python:** 3.11 – 3.14 (нативный интерпретатор Windows, **не WSL**)
* **Зависимости:** `PySide6`, `pywin32`, `pyinstaller`

## 🚀 Быстрый старт (запуск из исходников)

Откройте **PowerShell** в корне репозитория (`D:\Project\OptiSys`):

```powershell
# 1. Создание виртуального окружения Windows
python -m venv venv

# 2. Активация окружения
.\venv\Scripts\Activate.ps1

# 3. Установка зависимостей
pip install -r .\optisys\requirements.txt

# 4. Запуск приложения
python .\optisys\main.py
```

> **Примечание:** Для работы функций оптимизации системного диска, очистки `WinSxS` и установки драйверов через Windows Update запускайте терминал от имени администратора (или нажмите кнопку «🛡 Перезапустить от администратора» внутри программы).

---

## 📦 Сборка автономного `.exe` (PyInstaller)

Сборка упаковывает приложение и все зависимости в один исполняемый файл `optisys.exe` с манифестом автоматического запроса прав администратора (`uac_admin=True`).

### Вариант 1. Сборка через готовое виртуальное окружение
```powershell
cd .\optisys
..\venv\Scripts\pyinstaller.exe optisys.spec --noconfirm --clean
```

### Вариант 2. Автоматический скрипт сборки
```powershell
powershell -ExecutionPolicy Bypass -File .\optisys\build.ps1
```

Готовый исполняемый файл появится по пути:
```text
optisys\dist\optisys.exe
```

## 📁 Структура проекта

```text
OptiSys/
├── optisys/
│   ├── app/
│   │   ├── __init__.py
│   │   ├── cleaner.py          # Анализ/очистка кэша, Temp и поиск крупных файлов (> 100 МБ)
│   │   ├── drivers.py          # Поиск и установка драйверов через Windows Update COM API
│   │   ├── gpu_vendors.py      # Определение вендора GPU (PCI VEN_*) и официальных ссылок
│   │   ├── models.py           # Потокобезопасные датаклассы отчётов и задач
│   │   ├── optimizer.py        # Оптимизация сети/SSD/ОЗУ, автозагрузка и твики Windows 11
│   │   ├── registry_cleaner.py # Поиск битых записей реестра и создание .reg-бэкапов
│   │   ├── report.py           # Генерация отчётов в форматах HTML и JSON
│   │   ├── scanner.py          # Сбор данных об оборудовании, батарее и S.M.A.R.T. (WMI/Реестр)
│   │   ├── theme.py            # Тёмная тема оформления (Fluent / Slate Dark QSS)
│   │   ├── ui.py               # Главное окно, вкладки и обработчики событий (PySide6)
│   │   ├── utils.py            # Форматирование размеров/дат, проверка UAC, пути к логам
│   │   ├── widgets.py          # Векторные иконки, круговые индикаторы и анимации
│   │   └── workers.py          # Фоновые потоки QThread с инициализацией COM
│   ├── build.ps1               # PowerShell-скрипт автоматической сборки
│   ├── main.py                 # Точка входа и конфигурация логирования
│   ├── optisys.spec            # Спецификация сборки однофайлового optisys.exe
│   └── requirements.txt        # Зависимости Python
└── README.md                   # Документация проекта
```
